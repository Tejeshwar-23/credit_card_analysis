# Credit Card Fraud Detection

This project focuses on detecting potentially fraudulent credit card transactions using machine learning.

The project includes data preprocessing, exploratory data analysis, model training and evaluation, along with a web application for making predictions using the trained models.

## Project Overview

The main objective is to build a machine learning based system that can classify credit card transactions as legitimate or potentially fraudulent.

The project covers:

1. Data preprocessing
2. Exploratory data analysis
3. Feature preparation
4. Machine learning model training
5. Model evaluation
6. Fraud prediction through a web application

## Dataset

The dataset contains credit card transaction information that is used to train and evaluate the machine learning models.

The data is processed before training to prepare the features required by the classification models.

## Machine Learning

The notebook `credit_card_fraud.ipynb` contains the main machine learning workflow, including:

* Data preprocessing
* Exploratory data analysis
* Feature analysis
* Model training
* Model evaluation
* Fraud classification

The trained models are used by the backend application for prediction.

## Web Application

The `fraudapp` directory contains the application used to interact with the trained fraud detection models.

The application provides an interface through which transaction information can be processed and a prediction can be generated.

## Running the Notebook

Clone the repository:

```bash
git clone https://github.com/Tejeshwar-23/credit_card_analysis.git
cd credit_card_analysis
```

Install the required Python libraries:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter flask
```

Open the notebook:

```bash
jupyter notebook credit_card_fraud.ipynb
```

Run the notebook cells in order to reproduce the analysis and model training process.

## Results

The project includes model evaluation as part of the notebook. The trained models and their performance can be reviewed in `credit_card_fraud.ipynb`.

```text
Credit_Card_Fraud_Report.docx
```

## Disclaimer

This project is developed for educational purposes. The predictions generated by the system should not be treated as definitive evidence of fraudulent activity. Real-world fraud detection systems require additional validation, monitoring and domain-specific controls.
